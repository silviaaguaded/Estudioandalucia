# Estudio Andalucía

Sitio web institucional bilingüe (español / inglés) de Estudio Andalucía.

## Estructura

- `index.html`: contenido y estructura de la web.
- `styles.css`: sistema visual responsive.
- `script.js`: selector de idioma y navegación móvil.
- `.github/workflows/pages.yml`: despliegue automático en GitHub Pages.
- `.nojekyll`: publicación estática sin procesamiento Jekyll.

## Desarrollo

No requiere instalación ni proceso de compilación. Abrir `index.html` en un navegador o servir la carpeta con cualquier servidor estático.

## Publicación

El workflow de GitHub Actions publica el contenido de la rama `main` en cada push. En GitHub, comprobar en **Settings → Pages** que la fuente de publicación está configurada como **GitHub Actions**.
